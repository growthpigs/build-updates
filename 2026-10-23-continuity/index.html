Workstream 5 · the GitHub move

Blocked on one upgrade, then a lot of re-wiring

On 22 October the repo moved to Think-Big-Media. That organisation is on GitHub's free plan, which does not allow branch protection on private repos, so the required quality checks switched off. Roderic moved it back the same day; everything was checked intact and protection restored. done

  • Needed first: Think Big upgrades the organisation to GitHub Team waiting on Think Big
After the upgrade, the move itself
Move the code and re-apply branch protection on the three release branches.

Re-point the deploy hooks so Netlify and Render build from the new home.

Re-point the build pipelines and access tokens that are tied to the old organisation.

Sweep over 1,200 hard-coded references to the old repo name, across more than 400 files, in one reviewed change.
