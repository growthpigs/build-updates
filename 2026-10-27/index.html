Front · keeping each client's data separate

A second lock, inside the database

War Room has always filtered every query by client. Now the database enforces it too, so a mistake in one query can no longer show one client another client's rows.

  • The app connects to the database as a restricted account that can only see the signed-in client's rows on staging
  • Tested both ways on staging: with no client set it sees nothing; with Innovation Council set it sees Innovation Council's 324 documents and none of anyone else's
  • Reports, SWOT, chat, mentions and Daily Clips documents are all covered
  • A week of checks on staging, then it goes live
