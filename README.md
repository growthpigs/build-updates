# build-updates

Weekly War Room build-update decks (TLDR), served by GitHub Pages from `main` root at https://growthpigs.github.io/build-updates/.

One dated folder per week: `<YYYY-MM-DD>/index.html`, self-contained static HTML. Never overwrite a past week.

**PUBLIC:** anyone with the URL can read these. No secrets, rates or unredacted client data.
